Tooltips

CSS-only tooltips with multiple positions.

Tooltip Positions

On Different Elements

Hover over this text Link with tooltip

Code Example

<!-- Basic Tooltip -->
<button 
  data-ax-tooltip="Tooltip text" 
  data-ax-tooltip-position="top">
  Hover me
</button>

<!-- Positions: top, right, bottom, left -->
<button data-ax-tooltip="Top" data-ax-tooltip-position="top">Top</button>
<button data-ax-tooltip="Right" data-ax-tooltip-position="right">Right</button>
<button data-ax-tooltip="Bottom" data-ax-tooltip-position="bottom">Bottom</button>
<button data-ax-tooltip="Left" data-ax-tooltip-position="left">Left</button>
