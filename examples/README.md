# Examples

This directory contains standalone HTML examples demonstrating Axis Twelve components and utilities. Each example uses the CDN version and can be opened directly in a browser.

## Quick Links

- **Latest v2**: https://unpkg.com/axis-twelve@2/dist/axis-twelve.min.css
- **Full framework**: https://unpkg.com/axis-twelve/dist/axis-twelve.min.css
- **Modules**: https://unpkg.com/axis-twelve/dist/modules/

## Usage

### CDN Import

```html
<!-- Full framework -->
<link rel="stylesheet" href="https://unpkg.com/axis-twelve@2/dist/axis-twelve.min.css" />

<!-- Or individual modules -->
<link rel="stylesheet" href="https://unpkg.com/axis-twelve@2/dist/modules/axis-layout.min.css" />
<link rel="stylesheet" href="https://unpkg.com/axis-twelve@2/dist/modules/axis-buttons.min.css" />
```

### npm Import

```bash
npm install axis-twelve
```

```html
<link rel="stylesheet" href="node_modules/axis-twelve/dist/axis-twelve.min.css" />
```
