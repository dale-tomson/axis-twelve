# v1.1.0 - Performance Optimization

**Date:** February 7, 2026

## ⚡ Performance & Optimization

### CSS Size Reduction

**Major optimization of utility class generation**, reducing CSS file size by **25%** without breaking any existing features:

- **Minified CSS**: Reduced from 40.5KB to **30.5KB** (-10KB, -24.9%)
- **Gzipped**: Reduced from 6KB to **4.8KB** (-1.2KB, -20.7%)

### Responsive Utility Optimization

**Limited responsive spacing utilities** to commonly-used values only:

- **Before**: Generated 14 spacing values × 5 directions × 5 breakpoints = 350 classes per utility type
- **After**: Generated 6 spacing values × 5 directions × 5 breakpoints = 150 classes per utility type
- **Removed from responsive variants**: `2xl`, `3xl`, `4`, `8`, `10`, `12`, `16`, `20`, `24`
- **Kept for responsive**: `0`, `xs`, `sm`, `md`, `lg`, `xl`

**Impact**: All base utilities remain unchanged. Users can still use `.p-3xl`, `.m-24`, `.gap-20` etc. Only responsive variants like `.p-md-3xl` or `.m-lg-24` were removed.

**Affected utilities**:
- Padding utilities (`p-*`, `pt-*`, `pb-*`, `pl-*`, `pr-*`, `px-*`, `py-*`)
- Margin utilities (`m-*`, `mt-*`, `mb-*`, `ml-*`, `mr-*`, `mx-*`, `my-*`)
- Gap utilities (`gap-*`, `gap-x-*`, `gap-y-*`)

### Code Cleanup

**Removed redundant centering classes**:
- Removed `.box.center`, `.box.center-h`, `.box.center-v`, `.box.center-both` (duplicated default `.box` behavior)
- Kept `.box.center-start`, `.box.center-end`, `.box.center-between` (provide different functionality)
- **Savings**: ~200 bytes

**Cleaned up spacing variables**:
- Removed confusing inline comments from `$spacing-map`
- Simplified variable structure for better maintainability

## 📦 Distribution

## 🔧 Technical Details

**Files Modified**:
- `src/scss/_spacing.scss` - Optimized responsive utility generation
- `src/scss/_centering.scss` - Removed redundant classes
- `src/scss/_variables.scss` - Cleaned up spacing map

**Philosophy**: This optimization follows the **80/20 rule** - keeping the 20% of utilities used 80% of the time. Large spacing values are typically set once at the base level, not changed responsively across breakpoints.

## 📝 Migration Guide

### No Breaking Changes for Most Users

If you're using base utilities or responsive utilities with common values, **no changes needed**:

✅ **Still works**:
```html
<!-- Base utilities (all values) -->
<div class="p-3xl m-24 gap-20">

<!-- Responsive utilities (common values) -->
<div class="p-md-sm m-lg-xl gap-xl-md">
```

### For Users of Large Responsive Spacing

If you're using responsive utilities with large spacing values, replace with base utilities or custom CSS:

❌ **No longer available**:
```html
<div class="p-md-3xl m-lg-24 gap-xl-20">
```

✅ **Replace with**:
```html
<!-- Option 1: Use base utilities -->
<div class="p-3xl m-24 gap-20">

<!-- Option 2: Use custom CSS -->
<div class="custom-large-spacing">
```

### Removed Redundant Classes

If you're using these redundant `.box` modifiers, simply remove them:

```html
<!-- Before -->
<div class="box center">...</div>
<div class="box center-both">...</div>

<!-- After (box already centers by default) -->
<div class="box">...</div>
```
