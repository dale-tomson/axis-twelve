# v2.0.0 - Modular Architecture

**Release Date:** 2026-01-17

This major release introduces a complete architectural rewrite of Axis Twelve, moving from a monolithic structure to a modular system. Now featuring a built-in **Interactive Documentation Viewer**.

## 🚀 Major Features

### Modular Architecture
- **Zero-dependency modules**: Use `axis-buttons`, `axis-forms`, etc. independently.
- **Layered SCSS**: New structure with `abstracts`, `base`, `components`, `layout`, and `utilities` layers.
- **Improved Build System**: Generates both standalone and bundled CSS files.

### New Documentation System
- **Interactive Viewer**: A new Node.js powered documentation and examples explorer.
- **Static Example System**: Improved code snippets with high-contrast formatting and easy "Show Code" toggles.
- **Relational Navigation**: Seamlessly navigate between modules and versions with top/bottom relative links.
- **Search-friendly**: Improved SEO headers and clean URL structure for the viewer.

### Component Refinements
- **Buttons**:
    - Replaced unreliable emojis with lightweight, high-contrast SVG icons for better cross-platform rendering.
    - Improved color contrast for all semantic variants.
    - Added `.ax-btn--icon` for perfectly square icon actions.
- **Tooltips**:
    - Fixed detached arrows and positioning conflicts across all directions (top, bottom, left, right).
    - Added support for semantic variants (`success`, `danger`, `info`).
    - Fixed visibility issues on void elements (like inputs) via semantic mapping hints.
- **Cards**:
    - Fixed `.ax-card--shadow` modifier missing from the SCSS source.
    - Added `.ax-card__image` for robust image handling within card media containers.
    - Improved hover transitions for elevated cards.

## 🛠 Breaking Changes

This is a major version with breaking changes.

- **Class Naming**: All classes are now prefixed with `.ax-`.
    - `grid` -> `ax-grid`
    - `btn` -> `ax-btn`
    - `modal` -> `ax-modal`
- **Import Paths**:
    - HTML: `dist/axis-twelve.min.css` (or individual modules in `dist/modules/`)
    - SCSS: `@use 'axis-twelve/src/builds/axis-twelve'`
