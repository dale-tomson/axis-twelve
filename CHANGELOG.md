# Changelog

All notable changes to this project will be documented in this file.

## [2.2.0] - 2026-03-17

### Added
- **Container Queries**: Component-level responsive design with named containers
- **Print Styles**: Print-optimized stylesheets with element hiding
- **Empty States**: Component for empty/error states with variants
- **Range Slider**: Custom-styled range inputs with size/color variants
- **File Upload**: Drag-and-drop upload with preview and progress

### Enhanced
- **Toasts**: Auto-dismiss, progress bar, close button, all 6 positions
- **Skeletons**: Size variants, width utilities, container for grouped skeletons

## [2.1.0] - Previous Release

### Added
- Dark mode support
- Motion preferences
- Toast notifications
- Skeleton loaders

## [2.0.0] - Initial Release

### Added
- 12-column grid system
- Flexbox utilities
- Typography utilities
- UI components (buttons, cards, forms, modals, tables, tooltips)
