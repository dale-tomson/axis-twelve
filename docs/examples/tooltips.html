Tooltips

Contextual information hints that appear on hover or focus.

Basic Positioning

Directions

<button class="ax-btn" data-tooltip="Hello!" data-tooltip-pos="top">Top</button>
<button class="ax-btn" data-tooltip="Hello!" data-tooltip-pos="right">Right</button>

Styled Tooltips

Semantic Variants

<button data-tooltip="..." data-tooltip-variant="success">...</button>
<button data-tooltip="..." data-tooltip-variant="danger">...</button>
