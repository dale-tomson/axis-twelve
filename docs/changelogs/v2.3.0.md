# Changelog - v2.3.0

**Release Date:** March 18, 2026

## Overview

This release introduces major enhancements to dark mode support, comprehensive animation utilities, new form components, and a restructured directory layout for better organization.

## ⚠️ Breaking Changes

### Directory Structure Restructure

The following directory renaming has been applied to improve clarity and follow standard CSS framework conventions:

**Before:**

- `src/02-layout-grid/`
- `src/03-typography/`
- `src/04-ui-components/`
- `src/05-behavior/`
- `src/06-utilities/`
- `src/scss/` (legacy)
- `src/layout/` (legacy)
- `src/components/` (legacy)

**After:**

- `src/layout/`
- `src/typography/`
- `src/components/`
- `src/behavior/`
- `src/utilities/`

**Migration:** If you're importing SCSS files directly, update your import paths:

```scss
// Old
@use 'axis-twelve/src/06-utilities/dark-mode';

// New
@use 'axis-twelve/src/utilities/dark-mode';
```

## ✨ New Features

### Enhanced Dark Mode

- **System Preference Detection**: Automatic dark mode activation based on `prefers-color-scheme`
- **Auto Dark Mode Class**: `.ax-dark-auto` for automatic system detection
- **Manual Toggle Support**: `.ax-dark-manual` and `.ax-dark-force-light` for explicit control
- **25+ CSS Custom Properties**: Granular theming with variables for backgrounds, text, borders, and semantic colors
- **Component-Specific Overrides**: Dark mode support for all UI components including forms, cards, tables, navigation, modals, tooltips, buttons, badges, alerts, progress bars, dropdowns, accordions, skeletons, toasts, and empty states

```html
<!-- Auto-detect system preference -->
<html class="ax-dark-auto">
  <!-- Manual toggle -->
  <html class="ax-dark-manual">
    <!-- Force light mode override -->
    <html class="ax-dark-force-light"></html>
  </html>
</html>
```

### Animation Utilities

- **20+ Keyframe Animations**: fade, slide, scale, rotate, pulse, ping, bounce, shake, swing, wobble, heartbeat, flash, rubber band, jello, roll, zoom
- **30+ Preset Classes**: Ready-to-use animation classes like `.ax-fade-in`, `.ax-slide-up`, `.ax-scale-down`
- **Timing Utilities**: 11 duration classes, 9 delay classes, 9 easing variants
- **Enter/Exit State Classes**: For JS-managed transitions
- **Staggered Delays**: For sequential animations

```html
<!-- Preset animations -->
<div class="ax-fade-in">Content</div>
<div class="ax-slide-up ax-duration-500">Content</div>

<!-- Custom timing -->
<div class="ax-fade-in ax-duration-300 ax-delay-100">Content</div>

<!-- Multiple staggered elements -->
<div class="ax-fade-in ax-stagger-1">Item 1</div>
<div class="ax-fade-in ax-stagger-2">Item 2</div>
<div class="ax-fade-in ax-stagger-3">Item 3</div>
```

### New Form Components

#### Toggle Switch

iOS-style toggle switch with comprehensive customization:

- **3 Sizes**: sm (36px), md (44px), lg (52px)
- **5 Colors**: primary, success, danger, warning, info
- **States**: disabled, loading
- **Icon Support**: Optional on/off indicators

```html
<!-- Basic toggle -->
<label class="ax-toggle ax-toggle--primary">
  <input type="checkbox" class="ax-toggle__input" />
  <span class="ax-toggle__slider"></span>
</label>

<!-- With size and color -->
<label class="ax-toggle ax-toggle--lg ax-toggle--success">
  <input type="checkbox" class="ax-toggle__input" />
  <span class="ax-toggle__slider"></span>
</label>
```

#### Star Rating

SVG-based star rating component:

- **3 Sizes**: sm (16px), md (24px), lg (32px)
- **5 Colors**: primary, success, warning, danger, info
- **Half-Star Support**: For granular ratings
- **Interactive Mode**: Hover states and click handling
- **Read-Only Mode**: For displaying static ratings

```html
<!-- Basic rating (3.5 stars) -->
<div class="ax-rating ax-rating--md ax-rating--warning">
  <svg class="ax-rating__star ax-rating__star--filled">...</svg>
  <svg class="ax-rating__star ax-rating__star--filled">...</svg>
  <svg class="ax-rating__star ax-rating__star--filled">...</svg>
  <svg class="ax-rating__star ax-rating__star--half">...</svg>
  <svg class="ax-rating__star">...</svg>
</div>

<!-- Interactive rating -->
<div class="ax-rating ax-rating--interactive ax-rating--lg" data-rating="4">
  <svg class="ax-rating__star" data-value="1">...</svg>
  <svg class="ax-rating__star" data-value="2">...</svg>
  <svg class="ax-rating__star" data-value="3">...</svg>
  <svg class="ax-rating__star" data-value="4">...</svg>
  <svg class="ax-rating__star" data-value="5">...</svg>
</div>
```

## 📝 Usage Examples

### Dark Mode Integration

```html
<!-- Auto-detect (recommended) -->
<!DOCTYPE html>
<html class="ax-dark-auto">
  <head>
    <link rel="stylesheet" href="axis-twelve.css" />
    <link rel="stylesheet" href="axis-dark-mode.css" />
  </head>
</html>

<!-- Manual toggle -->
<script>
  function toggleDarkMode() {
    document.documentElement.classList.toggle('ax-dark-manual');
  }
</script>
```

### Animation Integration

```html
<!-- Simple fade in -->
<div class="ax-fade-in">Content appears</div>

<!-- Slide with delay -->
<div class="ax-slide-up ax-delay-300 ax-duration-500">Slides up after 300ms</div>

<!-- Staggered list -->
<ul>
  <li class="ax-fade-in ax-stagger-1">Item 1</li>
  <li class="ax-fade-in ax-stagger-2">Item 2</li>
  <li class="ax-fade-in ax-stagger-3">Item 3</li>
</ul>
```

```html
    />
  </svg>
  <!-- Repeat for 5 stars -->
</div>
```
