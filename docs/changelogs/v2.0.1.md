# Changelog - v2.0.1 (2026-02-08)

## 🌐 Logical Property Refactoring

This release focuses on internal refactoring to support multi-directional layouts (RTL/LTR) by transitioning from physical direction properties to logical counterparts.

### ✨ Added
- **Logical Properties** - Transitioned `margin`, `padding`, `inset`, and `text-align` properties to use logical values (`inline-start`, `inline-end`, `start`, `end`).
- **Browser Fallbacks** - Provided physical fallbacks for `inset` properties to ensure compatibility with 2020-era browsers (e.g., Safari 13).
- **Stylelint Support** - Updated Stylelint configuration to enforce logical property usage and specific ordering for better maintainability.

### 🛠 Fixed
- **Property Ordering** - Standardized the order of logical properties in SCSS source files to match Stylelint requirements.
- **Linting Issues** - Removed empty rulesets and fixed unexpected whitespace issues in `_centering.scss` and `_grid.scss`.

### 🔄 Changed
- **Spacing Utilities** - `.pl-*`, `.pr-*`, `.ml-*`, `.mr-*` classes now use logical properties under the hood, making them direction-aware.
- **Table Component** - Fixed mobile card transformation to use logical alignment.
- **Tooltip Component** - Refactored positioning logic to use logical insets and margins.

### 📊 Impact
This change is transparent to most users but enables seamless Right-to-Left (RTL) support when the `dir="rtl"` attribute is set on the document or container. Browser compatibility remains high (2020+).
