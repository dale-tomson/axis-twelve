# Changelog - v2.0.2 (2026-02-08)

## 📐 Subgrid Utility Integration

This release adds the `.ax-subgrid` utility class, allowing nested grid elements to inherit the track definitions of their parent grid. This is particularly useful for building complex components like cards or lists where items need to align across different containers.

### ✨ Added

- **Subgrid Class** - Introduced `.ax-subgrid { grid-template-columns: subgrid; }` for modern browsers.
- **Smart Fallback** - Included a manual 12-column grid fallback using `@supports` to maintain layout integrity on browsers without subgrid support.
- **Integration** - Seamlessly integrated into the `axis-layout` module and the core framework.

### 🛠 Technical Details

The fallback implementation uses the framework's `$grid-columns` variable to ensure consistent column counts across all grid types.

```scss
.ax-subgrid {
  display: grid;
  grid-template-columns: repeat($grid-columns, 1fr);

  @supports (grid-template-columns: subgrid) {
    grid-template-columns: subgrid;
  }
}
```

### 📊 Browser Compatibility

- **Subgrid**: Fully supported in Chrome 117+, Firefox 71+, and Safari 16+.
- **Fallback**: Works on all browsers supporting CSS Grid (2017+).
