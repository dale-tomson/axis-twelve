# v2.2.0 - Phase 3: Advanced Features

**Release Date:** March 17, 2026

## Overview

This release introduces Phase 3 advanced features including container queries support, print styles optimization, and five new component modules.

## New Modules

### Container Queries (`axis-container-queries`)
- Component-level responsive design using CSS Container Queries
- Named containers for cards, sidebars, and panels
- Responsive utilities for font-size, display, grid, and flex direction
- Visibility control based on container width
- Style container queries support

### Print Styles (`axis-print`)
- Print-optimized stylesheets
- Automatic hiding of interactive elements
- Typography optimized for paper (12pt base)
- Page break controls
- Optimized tables, forms, and code blocks

### Empty States (`axis-empty-states`)
- Component for empty/error states
- Variants: simple, minimal
- Sizes: sm, md, lg
- Icon, title, description, actions structure

### Range Slider (`axis-range-slider`)
- Custom-styled range inputs
- Sizes: sm, md, lg
- Color variants: primary, success, danger
- Label and value display support
- Marker support for scale indicators

### File Upload (`axis-file-upload`)
- Drag-and-drop file upload dropzone
- File preview with remove button
- Multiple file list with progress bars
- States: dragging, error, disabled
- Sizes: sm, md, lg

## Enhanced Modules

### Toasts
- Auto-dismiss with visual progress bar
- Close button styles
- Title and description structure
- All 6 positions (top-right, top-left, top-center, bottom-right, bottom-left, bottom-center)
- Slide animations

### Skeletons
- Size variants (sm, md, lg)
- Width utilities (w-1/4, w-1/3, w-1/2, w-2/3, w-3/4, w-full)
- Image skeleton variant
- Rounded modifier
- Container for grouped skeletons

## Documentation

- Comprehensive documentation for all new components
- Updated toasts and skeletons documentation
- Interactive HTML examples for all components
- CDN URLs updated to use unpkg.com without version tag

## Browser Support

- Container Queries: Chrome 90+, Firefox 110+, Safari 15.2+, Edge 90+
- Print Styles: All browsers with print support
- All other modules: Modern browsers

## Migration Guide

### CDN Usage
```html
<!-- Old -->
<link rel="stylesheet" href="https://unpkg.com/axis-twelve@2/dist/..." />

<!-- New -->
<link rel="stylesheet" href="https://unpkg.com/axis-twelve/dist/..." />
```

### Module Imports
All modules now available via CDN:
```html
<link rel="stylesheet" href="https://unpkg.com/axis-twelve/dist/modules/axis-empty-states.min.css" />
<link rel="stylesheet" href="https://unpkg.com/axis-twelve/dist/modules/axis-range-slider.min.css" />
<link rel="stylesheet" href="https://unpkg.com/axis-twelve/dist/modules/axis-file-upload.min.css" />

```
